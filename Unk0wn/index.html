Unk0wn

  • Moderation
  • Ticketing
  • Logging

A capable community-management bot designed to keep small and medium-sized Discord servers safe, organised, and easier to run.

Overview

Built to help moderators.

Unk0wn is built with discord.py and brings essential server-management tools into one focused bot.

  • Auto-moderation
  • Moderation tools
  • Ticketing
  • Level progression

Commands

Clear slash-command workflows.

  • /setup-help — Follow a step-by-step setup guide
  • /logging — Enable or disable server logging
  • /createlogs — Create a category and logging channels
  • /automod-settings — Configure auto-moderation
  • /kick — Remove a member with a recorded reason
  • /ban — Ban a member with a recorded reason
