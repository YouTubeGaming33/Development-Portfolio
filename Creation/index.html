The project

Less switching. Faster answers.

Creation was built for players of the Jamswerts’ Creation server, a Minecraft Java modpack community focused on the Create mod. It lets members check useful game-server information where the community already gathers: Discord.

Core features

Discord meets the game server.

  • Moderation tools
  • Live status monitoring
  • Online player list
  • Slash commands

Design goal

Useful at a glance.

The bot reduces friction for members who want a quick status check or player list, while giving community staff the moderation controls they need in the same interface.
