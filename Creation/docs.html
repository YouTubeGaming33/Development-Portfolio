Creation

01 / Overview

Discord meets Minecraft.

Creation is a utility bot for the Jamswerts’ Creation Minecraft Java community, a modpack server focused on the Create mod. It surfaces useful game-server information where members already gather: Discord.

Creation is built specifically for its community server. Exact slash-command names are not published here while the command surface continues to evolve.

02 / Features

Useful information at a glance.

  • Moderation tools
  • Live server monitoring
  • Online player list
  • Discord slash commands

03 / Server status

Check availability from Discord.

The status integration gives community members a quick way to see whether the Minecraft Java server is available without launching the game first.

  1. Open the server’s Discord community.
  2. Use Creation’s server-status interaction.
  3. Read the latest server information in Discord.

04 / Players

See who is online.

The player-list feature reports the currently online players, helping members decide when to join and making the game server feel connected to its Discord community.

05 / Staff tools

Community controls in the same place.

Alongside Minecraft information, Creation provides Discord moderation tools for community staff. This keeps essential server utilities and staff workflows inside one familiar interface.
