01 / Overview

Built for community operations.

Town Mayor is the dedicated Discord bot for The Modding Tavern. It combines staff tools, member support, progression, and community-server discovery in one system designed around the server’s workflow.

Town Mayor is a community-specific bot. Its commands and tools are available inside The Modding Tavern rather than through a public installation.

02 / Features

What Town Mayor handles.

  • Moderation and warnings
  • Private support tickets
  • Member levelling
  • Welcome messages
  • Audit logging
  • Anti-spam honeypot
  • Community server lookup
  • Uptime monitoring

03 / Moderation

Warnings with a clear history.

Moderation commands help staff record incidents and review a member’s previous warnings. Each warning receives a unique case code for easier reference.

/moderation warn

Record a warning against a member and create a unique case code.

/moderation check-warns

Review the warning history associated with a member.

04 / Support

Private help when members need it.

The ticket system gives members a direct route to the staff team without exposing their conversation in a public channel.

  1. Run the ticket command inside the community.
  2. Town Mayor creates a private support channel.
  3. The member and staff can discuss the request in one place.
/ticket open

Create a new private support channel.

05 / Server tools

Discover community servers.

Town Mayor connects to The Modding Tavern API so members can browse supplied servers and inspect live information without leaving Discord.

/server-lookup list_all

Browse the servers currently supplied by The Modding Tavern API.

/server-lookup lookup

Find the live details for a specific community server.
