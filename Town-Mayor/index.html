The project

One bot, built around one community.

Town Mayor is the dedicated Discord bot for The Modding Tavern. Instead of forcing a collection of generic bots into the community’s workflow, it brings staff operations, member support, progression, and server discovery together in one tailored system.

Core features

What it handles.

  • Moderation & warnings
  • Support tickets
  • Member levelling
  • Welcome messages
  • Audit logging
  • Anti-spam honeypot
  • Community server lookup
  • Uptime monitoring

Command surface

Selected slash commands.

  • /moderation warnRecord a warning with a unique case code.
  • /moderation check-warnsReview a member’s warning history.
  • /ticket openCreate a private channel for member support.
  • /server-lookup list_allBrowse servers supplied by The Modding Tavern API.
  • /server-lookup lookupFind the live details for a specific server.
